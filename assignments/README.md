# Задания

Оглавление всех заданий курса. Идём сверху вниз, каждое закрывается своим Pull Request.

| № | Задание | Уровень | Время |
|---|---|---|---|
| 01 | [Первый совместный Pull Request](01-first-steps/README.md) | новичок | 25–30 мин |

## Как сдавать

1. Ветка `student/<псевдоним>/task-NN` от свежего `main`.
2. Изменения и коммит.
3. Pull Request — по шаблону, он подставится сам.
4. Review одноклассника (свой PR сам не одобряешь).
5. Merge — задание засчитано ✅

Нужна помощь — [вопрос через issue](../../issues/new/choose).
Закончил — [сдай задание через issue](../../issues/new/choose).
