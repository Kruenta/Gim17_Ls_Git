# Gim17_Ls_Git
Практикум по GitHub для детей: README, issues, ветки, PR и совместные проекты — шаг за шагом.
# 🐙 GitHub-старт: первая ветка, первый PR

**Учимся пользоваться GitHub шаг за шагом: от первого README до командного проекта.**

Здесь мы не просто читаем теорию, а сразу пробуем руками:
создаём репозиторий, делаем коммиты, открываем issues,
работаем в ветках, отправляем Pull Request и проверяем работы друг друга.

Ошибаться можно. Сломать ничего нельзя.
Каждый коммит — это новый уровень. Каждый PR — маленькая победа.

## Что внутри

- 🧭 простые задания по шагам;
- 🌿 практика с ветками и Pull Request;
- 🐞 issues для задач и вопросов;
- 👀 review работ одноклассников;
- 🚀 мини-проекты и GitHub Pages;
- 🛡️ правила безопасной работы без личных данных.

## С чего начать

1. Прочитай задание в папке `assignments/`.
2. Создай ветку по правилу `student/имя/task-01`.
3. Сделай изменения и коммит.
4. Открой Pull Request.
5. Попроси одноклассника оставить комментарий.
6. После проверки — merge.

> Главное правило: в `main` напрямую не пушим.
> Сначала ветка, потом PR, потом review, потом merge.
